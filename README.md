# acheris-labs/homebrew-tools

Homebrew tap for Acheris Labs tools.

```sh
brew tap acheris-labs/tools
brew install acheris-labs/tools/scoreboard
```

## Packages

| Package | Description |
|:--------|:------------|
| [scoreboard](https://github.com/acheris-labs/agent-scoreboard) | Claude Code session scoreboard for the macOS menu bar |

## How this tap is maintained

Each project's release workflow renders its own cask from a template and
pushes it here — nothing in this repo is edited by hand. Casks live in
`Casks/`, command-line-only tools would live in `Formula/`.
